## Architecture Summary

The current delivery has one local-files connector feeding a normalized SQLite
projection. `main._sync_connector()` uses one `DiscoveryReport`, applies
permission metadata during ingestion, and persists tombstones and cursors
transactionally. `governance.retrieve()` remains the permission-filtered
evidence boundary. `answer()` selects and assembles cited claims on top of that
boundary, then uses the deterministic synthesis provider by default. DOCX,
XLSX, and PPTX parsing use the same ingestion, repository, retrieval, citation,
and receipt path as Markdown.
